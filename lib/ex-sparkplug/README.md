# ACS Sparkplug B library (Elixir)

A Sparkplug B library for Elixir services in ACS. It contains no
Factory+ specifics and no MQTT client: topic and payload go in, Elixir
data comes out.

Services use it through a path dependency:

```elixir
{:sparkplug_b, path: "../lib/ex-sparkplug"}
```

## Protobuf modules

`lib/sparkplug_b/proto.ex` is generated by
[protox](https://hex.pm/packages/protox) from `proto/sparkplug_b.proto`
and is committed, so building the library does not need `protoc`. Do
not edit it by hand.

`proto/sparkplug_b.proto` is vendored unchanged from
[Eclipse Tahu](https://github.com/eclipse-tahu/tahu/blob/master/sparkplug_b/sparkplug_b.proto)
at commit `46f25e79f3`. It is licensed under EPL-2.0, as its header
says; the rest of this library is MIT like the rest of ACS.

To regenerate after changing the `.proto` (needs `protoc` on the
`PATH`):

```sh
mix protox.generate \
    --output-path=lib/sparkplug_b/proto.ex \
    --include-path=proto \
    --namespace=SparkplugB.Proto \
    proto/sparkplug_b.proto
mix format
```
