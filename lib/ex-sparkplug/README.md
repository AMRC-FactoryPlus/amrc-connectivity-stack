# ACS Sparkplug B library (Elixir)

A Sparkplug B library for Elixir services in ACS. It contains no
Factory+ specifics and no MQTT client: topic and payload go in, Elixir
data comes out.

Services use it through a path dependency:

```elixir
{:sparkplug_b, path: "../lib/ex-sparkplug"}
```

## Decoding

```elixir
{:ok, payload} = SparkplugB.decode(bytes, timestamp_unit: :auto)

for metric <- payload.metrics do
  metric.alias      # 4
  metric.datatype   # :double
  metric.value      # 230.5
  metric.timestamp  # 1760000000123456789, always nanoseconds
end
```

Timestamps are always integer nanoseconds. The Sparkplug spec sends
milliseconds, but ACS edge agents send nanoseconds in the same field, so
ACS consumers pass `timestamp_unit: :auto`; the default, `:ms`, follows
the spec.

DATA messages may leave a metric's datatype out, because the birth gave
it. Such a metric keeps its raw protobuf value, such as
`{:long_value, 42}`, until `SparkplugB.Metric.with_datatype/2` converts
it. Datasets, templates, arrays and extensions are not converted yet
and also stay raw. See `SparkplugB.Metric` for the full rules.

## Topics

```elixir
{:ok, topic} = SparkplugB.Topic.parse("spBv1.0/Site_1/DDATA/Edge_1/Pump_3")
topic.type    # :ddata
topic.device  # "Pump_3"
"#{topic}"    # "spBv1.0/Site_1/DDATA/Edge_1/Pump_3"
```

Both the Sparkplug 3.0 host state topic (`spBv1.0/STATE/<host>`) and
the older `STATE/<host>` are parsed.

## Protobuf modules

`lib/sparkplug_b/proto.ex` is generated by
[protox](https://hex.pm/packages/protox) from `proto/sparkplug_b.proto`
and is committed, so building the library does not need `protoc`. Do
not edit it by hand.

`proto/sparkplug_b.proto` is vendored unchanged from
[Eclipse Tahu](https://github.com/eclipse-tahu/tahu/blob/master/sparkplug_b/sparkplug_b.proto)
at commit `46f25e79f3`. It is licensed under EPL-2.0, as its header
says; the rest of this library is MIT like the rest of ACS.

To regenerate after changing the `.proto` (needs `protoc` on the
`PATH`):

```sh
mix protox.generate \
    --output-path=lib/sparkplug_b/proto.ex \
    --include-path=proto \
    --namespace=SparkplugB.Proto \
    proto/sparkplug_b.proto
mix format
```
